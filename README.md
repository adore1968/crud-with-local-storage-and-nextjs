# CRUD App con Local Storage y Next.js

Este proyecto es una aplicación CRUD construida con **Next.js** que integra **Redux Toolkit** (utilizando la carpeta "app") y **TypeScript**. Además, hace uso de **React**, el **API Context** y los fundamentos de Next.js.

## Descripción

En esta aplicación, se implementan todas las operaciones CRUD (Crear, Leer, Actualizar, Eliminar) utilizando el almacenamiento local para persistir los datos. Se utilizan los métodos de Redux Toolkit para solicitar datos mediante `fetch` y gestionarlos en el estado de la aplicación.

## Tecnologías

- **Next.js**: Framework de React para aplicaciones del lado del servidor.
- **Redux Toolkit**: Herramienta para gestionar el estado global de la aplicación.
- **TypeScript**: Lenguaje de programación que añade tipos estáticos a JavaScript.
- **React**: Biblioteca para construir interfaces de usuario.
- **API Context**: Para compartir el estado entre componentes sin necesidad de prop drilling.
